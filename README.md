# 빌라 커뮤니티 앱 — 병합 버전

친구분의 세입자 화면 프로젝트를 **베이스**로 하고, 집주인 화면을 같은 디자인 시스템으로 다시 입혀서 하나의 앱으로 합쳤습니다.

## 무엇을 했나

1. **디자인 통일** — 친구분 파일의 컬러(네이비 `#353e6c` / 오렌지 `#ffa319` / 아이보리 `#faf8f4`), 폰트(Noto Sans KR), 카드·버튼·상단바 스타일을 기준으로 집주인 화면을 전부 다시 스타일링했습니다. 아이콘도 친구분 파일의 손그림 느낌 라인 아이콘 세트를 그대로 쓰고, 집주인 전용 아이콘(건물/영수증/공지/공구 등)은 같은 스타일로 새로 그려 넣었습니다.
2. **게시판 공유** — 세입자 화면의 "게시판"(공지 게시판 + 자유 게시판)을 두 역할이 함께 보는 단일 데이터로 만들었습니다. 집주인이 "공지 관리"에서 작성한 공지는 즉시 세입자 게시판에 나타나고, 세입자가 쓴 자유게시판 글도 하나의 데이터로 관리됩니다.
3. **데이터 통합** — 두 파일이 서로 다른 가상 데이터(건물명, 세입자 이름 등)를 쓰고 있어서, PRD 11장 시드 데이터(라일락빌라, 101/201/202호, 김세입·이세입·정세입, 박집주)로 통일했습니다. 세입자가 접수한 하자신청은 집주인의 "내 건물 관리" 화면에도 그대로 반영됩니다.

## 폴더 구조

```
src/
  theme.ts              # 색상 토큰 (친구 파일 기준)
  icons.tsx             # 공용 아이콘 세트
  ui.tsx                # 공용 컴포넌트 (NavHeader, Card, StatusBadge 등)
  data.ts                # 데이터 모델 + 시드 데이터 (PRD 11장 기준)
  store.tsx              # 공유 상태 (하자신청/공지/게시글/관리비) — 두 역할이 함께 읽고 씀
  screens/
    StartScreen.tsx       # 역할 선택 화면
    tenant/               # 세입자 화면 10개 (친구 파일 기반)
    landlord/             # 집주인 화면 10개 (재스타일링)
  App.tsx                 # 최상위 라우터
```

## 실행 방법

```
npm install
npm run dev
```

## 참고 — 로컬 확인 관련

이 작업은 네트워크가 차단된 환경에서 진행되어 `npm install`을 실제로 실행해보지 못했습니다. 대신 모든 `.ts`/`.tsx` 파일을 TypeScript 컴파일러로 구문(syntax) 검증했고, 타입은 두 원본 파일에서 이미 검증된 패턴을 그대로 따랐습니다. 실행 중 타입 에러가 발견되면 대부분 사소한 것이라 쉽게 고칠 수 있을 거예요.
